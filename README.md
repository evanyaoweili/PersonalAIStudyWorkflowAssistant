# PersonalAIStudyWorkflowAssistent

CMU AI Agent Course Capstone project.

This repository is being used to track the progress of the project from planning through implementation and review.

## Project overview

The goal of this project is to build a personal AI study workflow assistant that helps organize study tasks, manage progress, and support a repeatable learning routine.
